# PDF工具箱 自述文档

## 📖 项目简介

**PDF工具箱** 是一款纯本地运行、无联网组件、无广告的 Windows 桌面工具，集成了 PDF 转换、合并、拆分、权限设置、隐私清理以及专业的页面编辑功能。所有处理均在用户本机完成，文件不会上传至互联网。

## ✨ 功能特性

### 一、转换与配置

| 子功能 | 说明 |
|--------|------|
| **PDF转图片** | 支持 PNG / JPG / JPEG / BMP 格式，可选 150 / 300 / 600 DPI，支持按页码范围提取 |
| **图片转PDF** | 支持 JPG / PNG / BMP / GIF / TIFF，可指定页面大小（A4、A3、A5、Letter、Legal 或自定义尺寸） |
| **设置权限** | 可为 PDF 设置打印、复制、注释、填写等权限，支持设置打开密码（AES-256 加密） |
| **清除数据** | 清除 PDF 中的元数据、作者、创建者、时间戳、部分内嵌脚本等隐私信息 |
| **拆分PDF** | 三种模式：提取指定页合并为一个 PDF、提取指定页为独立单页文件、全部拆分 |
| **PDF页面编辑** | 在浏览器中打开专业页面编辑器（详见下文） |

### 二、文档处理

| 子功能 | 说明 |
|--------|------|
| **Word转PDF** | 调用本机 Microsoft Word 或 WPS 进行转换，支持多个文档合并为一个 PDF |
| **合并PDF** | 将多个 PDF 按指定顺序合并为单个 PDF 文件 |

### 三、PDF 页面编辑器（网页版）

点击「PDF页面编辑」按钮后，程序会在本机启动一个仅绑定 `127.0.0.1` 的本地 Web 服务，并在默认浏览器中打开编辑器。**PDF 文件不会上传互联网**，浏览器仅作为操作界面。

**核心功能：**

- 📄 **打开 / 添加文件**：支持同时打开多个 PDF 并插入到指定位置
- 🗑 **删除页面**：选中后一键删除
- 🔄 **旋转页面**：支持左旋 / 右旋 90°
- 🖱 **拖拽排序**：鼠标拖拽即可调整页面顺序（支持多选批量移动）
- ↩️ **撤销 / 重做**：支持 Ctrl+Z / Ctrl+Y 快捷键
- 🔍 **页面预览**：悬停缩略图点击放大镜可查看大图，支持缩放（Ctrl+滚轮 / Ctrl+±/0）
- 💾 **多格式保存**：可保存为 PDF，或导出为 PNG / JPG / BMP / TIFF 图片（多页自动打包为 ZIP）
- 📤 **导出选中**：可将选中的页面按当前顺序单独导出

**编辑器快捷键：**

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 重做 |
| `Delete` | 删除选中页面 |
| `←` / `→` | 预览时切换上下页 |
| `Ctrl + +` / `Ctrl + -` | 预览时放大 / 缩小 |
| `Ctrl + 0` | 预览时适应窗口 |
| `Esc` | 关闭预览 |

## 🚀 快速开始

### 环境依赖

- Python 3.8+
- Windows 10 及以上

### 安装依赖

```bash
pip install PyMuPDF img2pdf pypdf Pillow
```

**可选依赖（用于增强功能）：**

```bash
# 拖拽文件功能
pip install tkinterdnd2

# Word转PDF功能（Windows）
pip install pywin32
```

### 运行程序

```bash
python v6.4.0.0.py
```

> 💡 打包为 exe 时，请确保 `2x2.ico`（程序图标）、`i.png`（关于页图标）随资源一同打包。

## 🛠️ 使用说明

### 通用操作流程

1. 在「**转换与配置**」标签页中选择需要的子功能
2. 通过「**选择文件**」按钮或**拖拽**方式导入文件（支持文件夹）
3. 设置输出目录与重名策略（逐个询问 / 自动覆盖 / 自动重命名）
4. 点击「**开始处理**」按钮执行任务

### 重名策略

| 策略 | 行为 |
|------|------|
| 逐个询问 | 遇到重名文件时弹窗询问是否覆盖（60 秒超时自动取消） |
| 自动覆盖 | 直接删除旧文件后写入 |
| 自动重命名 | 自动添加 `_1`、`_2` 等后缀 |

### 页码格式

支持以下写法（页码从 1 开始）：

- `all` 或留空：全部页面
- `1,3,5`：指定单页
- `1-3`：范围
- `1-end`：从第 1 页到最后一页
- `1-3, 5, 8-10`：混合写法

## ❓ 常见问题

**Q1：Word转PDF 提示未检测到 Office？**
A：请确认已安装 Microsoft Word 或 WPS，且已安装 `pywin32` 依赖。

**Q2：PDF 编辑器打开后无法访问？**
A：请检查浏览器是否被代理/防火墙拦截。编辑器仅绑定本地地址，如仍无法访问，请尝试关闭代理后刷新。

**Q3：清除数据后文件仍包含敏感信息？**
A：本功能仅清除基础元数据、文档信息、部分脚本，**无法清除**嵌入内容、批注、隐藏图层等深层数据，请自行评估使用。

**Q4：文件已加密无法编辑？**
A：编辑器会拒绝加载已加密 PDF，请先使用「设置权限」子功能中的解密方案（或第三方工具）解除密码。

**Q5：拖拽功能不可用？**
A：请安装 `tkinterdnd2`：`pip install tkinterdnd2`。
